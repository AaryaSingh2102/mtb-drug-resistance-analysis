Identification of Drug Resistance-Associated Mutations in Mycobacterium tuberculosis

Project Overview

This independent bioinformatics project analyses whole-genome sequencing data of Mycobacterium tuberculosis to identify genetic variants associated with anti-tuberculosis drug resistance.

The project uses bioinformatics tools to process sequencing reads, perform quality control, map reads against a reference genome, identify genetic variants and analyse potential drug resistance-associated mutations.

Project Objectives

* Analyse paired-end sequencing data of M. tuberculosis.
* Perform quality control and read preprocessing.
* Map sequencing reads against the H37Rv reference genome.
* Identify and annotate genetic variants.
* Analyse mutations associated with anti-tuberculosis drug resistance.
* Visually inspect selected genomic regions using IGV.

Tools and Software

* FastQC
* fastp
* BWA
* SAMtools
* BCFtools
* SnpEff
* TB-Profiler
* Integrative Genomics Viewer (IGV)

Project Workflow

1. Download sequencing data from NCBI.
2. Perform quality control of raw reads.
3. Trim and filter sequencing reads.
4. Align reads to the reference genome.
5. Process alignment files and assess mapping quality.
6. Identify and annotate genetic variants.
7. Analyse drug resistance-associated mutations using TB-Profiler.
8. Visually inspect selected variants using IGV.

Repository Contents

* Results/ – Variant tables, quality-control summaries, resistance analysis and command history.
* Documentation/ – Final project report in PDF format.
* IGV_Screenshots/ – Screenshots of selected genomic regions inspected using IGV.

Important Note

Drug resistance predictions generated through bioinformatics analysis are computational findings and do not replace laboratory-based phenotypic drug susceptibility testing.
